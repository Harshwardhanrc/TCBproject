# TCBproject
source of tcb project working
This is a simple budget tracker web application that allows user to manage their expenses, track spending, and monitor their remaining budget.
The Frontend of this project is made using HTML, CSS and JavaScript. 
The Backend of this project is made using NodeJS and ExpressJS, MongoDB's Mongoose is used for database.
The Backend of this project is deployed using Render.
The Frontend is Deployed using Vercel.
link- https://budget-tracker-chi-neon.vercel.app/
